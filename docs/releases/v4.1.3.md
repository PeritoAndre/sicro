## SICRO 4.1

Correção: no Linux, o croqui não conseguia buscar o traçado do OpenStreetMap.

### Downloads

| Sistema | Arquivo | Como instalar |
|---|---|---|
| **Windows 10/11 (64 bits)** | `SICRO-4.1.3-windows-x64-setup.exe` | Execute e siga o instalador. O FFmpeg já vem junto. |
| **Ubuntu 22.04+, Debian 12+ e derivados** | `sicro_4.1.3_amd64.deb` | `sudo apt install ./sicro_4.1.3_amd64.deb` (o apt já instala o ffmpeg e os plugins de vídeo) |

`SHA256SUMS.txt` traz os hashes para conferir o download (`sha256sum -c SHA256SUMS.txt`; no Windows, `Get-FileHash <arquivo>`).

**Windows:** o instalador não tem assinatura digital. Se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.

### O que mudou

- **Importar do OpenStreetMap volta a funcionar no Linux.** Desde a 3.1 o Linux toca vídeo direto do arquivo, e para isso a página do app é tratada como "local" pelo WebKit — que, por regra, não deixava página local carregar nada de outro site: a consulta ao Overpass caía com "Falha de rede: Load failed" e o mapa de referência ficava em branco. Agora tanto a consulta ao Overpass quanto os tiles do mapa saem pelo lado Rust do programa (como os downloads de IA), identificando-se com o nome e a versão do SICRO. Continua saindo só a área geográfica; nenhum dado do caso.
- **Overpass ocupado não derruba mais a busca.** O servidor público vive respondendo 504; o SICRO agora tenta os três nós oficiais antes de desistir.
- **Coordenada de exemplo do wizard corrigida.** Estava no hemisfério sul (meio do rio); Macapá fica a 0,0345 **Norte**.

### Vindo do 4.1.2

Os casos abrem normalmente; nenhum formato mudou.
